# Проект: предсказание стоимости автомобилей

## Описание проекта

В рамках проекта была решена задача предсказания стоимости автомобилей на основе различных характеристик. Были проведены предобработка данных, исследовательский анализ, обучение и сравнение нескольких моделей линейной регрессии.

Также было разработано Streamlit-приложение для визуализации данных и предсказания различных характеристик на основе линейной регрессии.


## Используемые данные

В датасете содержатся характеристики автомобилей, включая:
- год выпуска
- пробег
- тип топлива
- тип коробки передач
- мощность двигателя
- крутящий момент
- количество мест
- тип владельца
- и другие признаки

Целевая переменная:
- `selling_price`

## Предобработка данных

В ходе работы были выполнены:
- удаление дубликатов
- обработка пропусков
- преобразование признака `torque`
- выделение бренда автомобиля из признака `name`
- кодирование категориальных признаков
- масштабирование числовых признаков

## Исследовательский анализ данных

Были построены:
- распределения признаков
- scatterplot-графики
- матрица корреляций
- визуализация зависимости цены от различных признаков

## Обучение моделей

В проекте были обучены и сравнены:
- Linear Regression
- Lasso Regression
- Ridge Regression
- ElasticNet
- модель с L0-регуляризацией

Для подбора гиперпараметров использовался GridSearchCV.

## Результаты

Лучший результат показала Ridge-регрессия.

Основные метрики:
- R² ≈ 0.77
- business metric ≈ 0.29

Использование регуляризации и категориальных признаков позволило значительно улучшить качество модели.

## Оценка разработанного сервиса

Приложение получилось достаточно удобным для базового анализа данных и быстрого обучения модели. Пользователь может загрузить собственный CSV-файл, визуализировать признаки и получить предсказание без необходимости работать напрямую с кодом.

Лучше всего удалось реализовать визуализацию распределений признаков, scatterplot-графики и матрицу корреляций. Также удобно отображаются коэффициенты модели, что позволяет оценить важность признаков.

Менее удачной частью можно считать ввод данных для предсказания после One-Hot Encoding, так как пользователю приходится видеть большое количество признаков после кодирования категориальных переменных.

Основное ограничение текущей версии заключается в том, что модель обучается внутри приложения после загрузки датасета, а также в отсутствии более удобного интерфейса для категориальных признаков.

В следующей итерации планируется:
- использовать заранее сохранённую модель;
- улучшить интерфейс ввода признаков;
- добавить больше типов визуализаций;
- реализовать более удобную обработку категориальных признаков;
- улучшить внешний вид приложения
